# Travel-Management-Application-using-SAP-ABAP-RAP
Developed a Travel Management application using SAP ABAP RAP in Eclipse ADT. Created a custom travel table and generated a RAP business object with CDS views and an OData V4 UI service. Implemented read-only field control for Status and a save determination to set new trips to status 'N'. Tested the service using SAP Fiori Elements Preview.


-Developed a Travel Management application using SAP ABAP RESTful Application Programming Model (RAP).
-Created a custom database table and generated a RAP Business Object with an OData V4 UI service.
-Implemented field control to make the Status field read-only on the UI.
-Created a determination to automatically set the status of newly created travel records to 'N' during save.
-Published the service binding and tested the application using SAP Fiori Elements Preview.

Technology Stack:
- SAP ABAP Cloud
- ABAP RESTful Application Programming Model (RAP)
- Core Data Services (CDS Views)
- ABAP Behavior Definition & Behavior Implementation
- OData V4
- SAP Fiori Elements
- Eclipse IDE (ADT)
- SAP BTP ABAP Environment
